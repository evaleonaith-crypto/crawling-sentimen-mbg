# YouTube Sentimen MBG 
 
## Scheduler & Execution 
* **Scheduler:** Menggunakan **Windows Task Scheduler** bawaan OS agar skrip berjalan otomatis sesuai jadwal tanpa aplikasi tambahan. 
* **Cara Running:** 
  - **Manual:** `python crawling_mbg.py` 
  - **Otomatis:** Windows Task Scheduler (Action: `python.exe`, Argument: `crawling_mbg.py`)
